# MediOps

MediOps is a full-stack healthcare management system designed to manage patients, medical resources, emergencies, and related healthcare workflows.

## Project Structure

- `backend/` - Spring Boot REST API
- `frontend/` - React + TypeScript application
- `database/` - Database scripts and migrations
- `docs/` - Architecture and project documentation

## Technology Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React
- TypeScript

### Infrastructure
- Docker
- Docker Compose
